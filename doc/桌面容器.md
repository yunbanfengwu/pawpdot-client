# PawPdot 桌面容器

## 启动

需要 Node.js 24.9 或更新版本。进入 `pawpdot-client` 后执行以下命令。

```powershell
npm ci
npm start
```

首次安装会下载 Electron 与 DeepSeek Harness。启动后直接打开 PawPdot 桌面窗口。拖动自绘标题栏的空白区域可移动窗口，双击切换最大化和还原。右上角依次为最小化、最大化／还原和关闭。普通窗口可从四条边和四个角调整尺寸。

Windows 主窗口和应用窗口使用 `assets/brand/pawpdot.ico`，由现有品牌 SVG 转换，包含 16–256px 的七档尺寸。任务栏应用标识为 `PawPdot.Desktop`。

左下角账号菜单和「设置 → PawPdot 账号」共用登录状态。设置里的「账号与余额」由 DeepSeek Harness 官方账号插件提供，读取 DeepSeek 授权账号的头像、模型和余额。「PawPdot 账号」显示 PawPdot 自己的登录方式，也可登录、注册或退出。DeepSeek 授权和桌面中的 HTTP、HTTPS 外链使用系统默认浏览器。桌面端复用 [PawPdot 账号服务](../../pawpdot-superroot/doc/用户管理.md)，默认连接 `127.0.0.1:3195`。服务使用其他本机端口时，启动桌面端前将 `PAWPDOT_PORT` 设为相同端口。已有 DeepSeek 账号需要重新授权一次，才能补存历史账号缺少的头像地址。

模型设置同时保留两条 DeepSeek 路由。`DeepSeek Account` 使用官方授权凭据，可读取账号模型和余额。`DeepSeek` 使用 API Key，适合环境变量、保存的 API Key 或自定义模型配置。API Key 卡片提示环境变量时，只表示该 API Key 路由没有配置密钥，不影响已授权的账号路由。

## 架构

- `backend/main.cjs` 管理无框 Electron 窗口和工作台视图。Harness 的独立视图铺至窗口顶边，顶部内容为按钮和拖拽区留空。窗口按钮与中央灵动岛由 `backend/desktop-chrome.cjs` 叠加。标题栏透明，浅色主题下显示页面自身的浅色背景。12px 圆角与 1px 浅灰细边由界面在透明背景上绘制。Windows 最大化时填满当前显示器的工作区，恢复时回到之前的窗口位置和尺寸。各渲染进程均启用沙箱与上下文隔离，关闭 Node 集成。
- `backend/harness.cjs` 随窗口启动官方 Harness `0.2.2-rc.2` 的 Web profile。Harness 作为由桌面程序管理的子进程运行，服务只绑定本机回环地址，由系统分配端口。主进程只为当前窗口到该实例的 HTTP 和 WebSocket 请求附带本机凭据。
- `frontend/` 承载 PawPdot 自绘标题栏、启动画面与工作台外置主题。窗口操作仅通过本地外壳的 IPC 桥调用。Harness 的浅色、深色和跟随系统设置同步到外壳标题栏及边框。外壳占满视口，工作台内容自行管理滚动。会话、设置和原生 Cordis 插件界面由 Harness 提供。
- Windows 数据位于 `%APPDATA%/Pawpdot Client`。独立的 `harness/` 保存 profile 和会话，`workspace/` 用作默认工作区。退出桌面程序会结束它启动的 Harness 进程。

透明窗口的实现参考 [robot-dpo 窗口配置](../../../../work/taishan-dpo/solution-plasterboard-dpo-web/robot-dpo/electron/main.js) 与 [页面透明底色](../../../../work/taishan-dpo/solution-plasterboard-dpo-web/robot-dpo/src/App.vue)。

## Harness 适配登记

| 路径 | 用途 | 适用版本 |
| --- | --- | --- |
| `backend/harness.cjs` | 启动隔离 profile，取得本机鉴权并交给窗口宿主。 | Harness 0.2.2-rc.2 |
| `frontend/account/`、`backend/account.cjs` | 替换 `settings.launcher` 的登录入口，通过桌面宿主连接 PawPdot 账号服务。使用一次性链接在默认浏览器发起 DeepSeek 授权，由桌面端接收登录结果。 | Harness 0.2.2-rc.2、Electron 44.7.0 |
| `backend/main.cjs`、`backend/window-preload.cjs` | 管理窗口与工作台视图布局、校验窗口操作来源、注入工作台主题和认证。 | Electron 44.7.0、Harness 0.2.2-rc.2 |
| frontend/workbench.css | 通过 Harness 主题变量定制字体、侧栏和键盘焦点。 | Harness 0.2.2-rc.2 |
| backend/workbench-preload.cjs | 读取工作台的 data-ds-dark-theme 状态并通知桌面外壳。 | Harness 0.2.2-rc.2 |
| plugins/phone-connector/、ackend/harness.cjs | 迁入 AuDoter 统一中继手机连接，注册扫码配对、终端撤销、会话/附件/语音桥接和手机侧栏入口。 | AuDoter udoter.relay.v1、Harness 0.2.2-rc.2 |

Harness 保留上游的 Cordis 插件加载机制。Pi 执行底座仍是后续接入项。已核对 rc.2 官方 Agent Loop 的入口，AuDoter 的 Pi 插件所依赖的 `agent/external-step` 是旧项目的本地钩子。Pi 接入时要先验证独立适配与原生会话、工具权限、事件和停止语义能协作，再启用实际执行。

独立 Cordis 插件 `frontend/onboarding/` 通过 `settings.onboarding` 同名插槽替换跳过 `welcome-notice`。`backend/harness.cjs` 将它和首页插件分别装载。适用 Harness 0.2.2-rc.2。已在全新隔离配置中验证首次启动、刷新和模型设置，并在省略首页插件的隔离配置中确认预览说明也未出现。升级时复核插槽标识和完成回调。

## 工作台导航与主对话

- `frontend/branding/` 是 Harness 的 Cordis 插件，注册窄栏、主对话和页面样式。窄栏从上到下依次为首页、对话、自动化、插件和应用。只有对话页展开 Harness 原有的工作区、会话列表和新会话入口。左下角账号菜单保留设置入口。
- 首页的宠物区域预留 `pawpdot.home.pet` 插槽，底部复用原生输入组件。主对话的会话 ID 保存在当前 profile，由 Harness 为它管理独立工作区。首页切换和重启沿用同一会话，普通会话按各自工作区浏览。
- 桌宠以独立 Cordis 插件或应用包交付，由包注册 `pawpdot.home.pet` 并管理素材、界面、交互和状态。桌宠需要与主对话交互时调用宿主提供的能力。启停或替换桌宠走 Cordis 生命周期，首页在插槽空置时留白。
- `frontend/apps/` 使用 Harness 的原生插件清单和 Cordis 主面板，兼容 AuDoter 已有 `audoter.pluginType: ui-app` 应用包。应用需要安装到 PawPdot 自己的配置。应用包的界面和工作区数据由 Harness 插件管理，Electron 提供独立的应用窗口。
- Harness 0.2.2-rc.2 的适配点为 `shell.overlay`、`main`、`conversation.hero.frame` 和原生侧栏的布局标记。升级时复核会话列表避让、头像菜单键盘操作、主对话输入和应用窗口。
- 本机隔离开发版已验证首页输入可编辑、主对话重启复用、会话列表在常规和窄窗口避开导航、设置与登录菜单支持键盘切换、自动化和插件页可以打开，以及草图设计师应用包可以在独立窗口加载。

## 全局灵动岛

- 每个 PawPdot 窗口顶部有一个常驻岛。切页和打开设置会更新当前页面，活动列表在窗口间共享。悬停或点击展开。窗口顶边两侧可拖动，右上角三个按钮悬浮。按 F6 可从工作台进入岛，按 Esc 返回。
- Harness 页面与 Cordis 客户端插件调用 `window.pawpdotIsland.publish({ id, pluginId, pageId, title, detail, status, progress })`。同一插件用相同 `id` 更新活动，撤回调用 `dismiss(id, pluginId)`。状态可取 `info`、`running`、`success` 或 `error`。有明确百分比时传 `progress`。
- 本地应用包通过隔离桥调用 `window.pawpdotIsland.publish(item)` 或 `dismiss(id)`。宿主按打开的应用窗口绑定插件身份。活动列表在本次桌面进程内保留。
- 自动化使用 Harness 的任务目录与变更事件，显示「任务已排队或正在运行」和「任务已投递到会话」等状态。明确进度由业务插件上报。

## Windows 验证

- 功能检查。Windows 10、150% 显示缩放。使用实际鼠标双击和中间按钮交叉验证最大化与还原，实测移动窗口及侧边、右下角缩放。Windows 命中检测覆盖四条边和四个角。通过 Harness 设置切换深色、浅色和跟随系统，检查标题栏、边框和侧栏。
- 视觉检查。工作台就绪后标题栏保持显示，外壳高度等于视口。浅色及深色四边均有连续边线。12px 右下角在深灰测试底色上确认透出底色。[右下角放大截图](桌面圆角验证.png)
